# AI学习机家长调查问卷（网页版 · 正式稿 v3）

依据《学习有"机"，"信"关天下——武汉市中小学生家长AI学习机信任形成机制与付费意愿影响因素的调查》报告及附录A"调查问卷（正式稿 v3）"制作。

**在线地址**：https://che311-cyber.github.io/ai-learning-machine-survey/

## 问卷结构（与附录A一致）
1. 甄别题：S1 孩子学段（其他→终止）、S2 是否听说过、S3 是否已购（分流已购组/潜在组）
2. 量表：37 个 Likert-5 题项（PE/EE/SI/PV/TRA/TRB/TRC/PRA/PRB/PRC/ATT/BI），题序按固定随机种子 20261017 在构念间打乱；陷阱题"本题请选择'比较不同意'"固定在第 24 题位
3. BI 题项按组分卷措辞（已购=续费/继续使用，潜在=购买/优先选择），见附录A表A-2
4. 行为题：已购组 5 题（品牌A—F脱敏/价格段/持有时长/每周使用时长/8项功能多选）；潜在组 2 题（5项信息渠道/6项未购原因多选）
5. 人口学：家长角色、年龄、学历、家庭月收入、城区（孩子学段沿用 S1）

## 数据回收
- 未配置后端时：答卷保存在**填写者本机**浏览器 localStorage；在该设备打开 `网址/#admin` 可查看并导出 CSV/JSON（含陷阱题通过标记、最长直线作答标记，对应报告中的清洗规则）。
- 如需集中收集：把 `config.js` 中 `endpoint` 改为任意接收 POST JSON 的接口地址即可（例如腾讯云开发/自建服务的 /submit）。字段结构见导出的 JSON。
